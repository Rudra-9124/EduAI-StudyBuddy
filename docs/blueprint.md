# **App Name**: EduAI StudyBuddy

## Core Features:

- PDF Upload: Implement file upload interface for PDF documents.
- Text Extraction & Cleaning: Extract and clean text content from uploaded PDFs.
- Text Chunking: Divide the extracted text into manageable segments.
- AI Content Summarization: Summarize content from each text chunk using an LLM. LLM uses a tool to decide which information should be used in the summary.
- AI Quiz Generation: Generate multiple-choice questions and answers based on the text content. LLM uses a tool to decide which questions should be included.
- Quiz Interface: Provide an interface for users to take quizzes, select answers, and receive scores with feedback.
- Summary Display: Display generated summaries for each text chunk for quick content review.

## Style Guidelines:

- Primary color: Light pastel blue (#A8D0E6) to promote calmness and focus.
- Background color: Off-white (#F0F4F8), nearly the same hue as the primary, for a soft and clean interface.
- Accent color: Soft orange (#F4A261), analogous to blue, to highlight interactive elements.
- Body text: 'PT Sans' (sans-serif) for body text to ensure readability.
- Headline text: 'Playfair' (serif) for headlines to offer elegance and clarity.
- Use clean, line-style icons to represent different sections and actions.
- Use a clean and structured layout to organize content clearly.
